# docs

프로젝트 문서를 일괄 생성합니다. 포트폴리오, 업무일지, 개발일지를 한 번에 작성합니다.

## 사용법

```
/dev_ch:docs [options]
```

## Options

- `--path <경로>`: 문서를 작성할 프로젝트 경로 (기본값: 현재 디렉토리)
- `--since <날짜>`: 이 날짜 이후의 커밋만 분석 (예: 2024-01-01)
- `--skip-confirm`: 확인 질문 건너뛰기

## 동작

이 커맨드는 다음 에이전트들을 **병렬로** 실행합니다:

1. **portfolio-writer**: 프로젝트 포트폴리오 작성/업데이트
2. **daily-work-writer**: 업무일지 생성 (보고용)
3. **daily-work-details-writer**: 상세 개발일지 생성 (개인 기록용)

## 인터랙티브 모드

`--skip-confirm` 옵션이 없으면 실행 전 다음을 확인합니다:

- 문서를 작성할 프로젝트 경로가 맞는지
- 어느 날짜부터 커밋을 분석할지
- 어떤 문서를 생성할지 (portfolio/worklog/devlog 선택)

---

$ARGUMENTS

다음 작업을 수행하세요:

1. **사용자에게 확인 질문** (--skip-confirm이 없는 경우):
   - AskUserQuestion 도구를 사용하여 다음을 확인:
     - "이 경로의 프로젝트 문서를 작성할까요? [현재 경로]"
     - "어느 날짜 이후의 커밋을 분석할까요?" (옵션: 최근 1주일, 최근 1개월, 전체, 직접 입력)
     - "어떤 문서를 생성할까요?" (multiSelect: portfolio, worklog, devlog)

2. **에이전트 병렬 실행**:
   - 선택된 문서 유형에 따라 해당 에이전트들을 Task 도구로 병렬 실행
   - 각 에이전트에게 프로젝트 경로와 날짜 범위 전달

3. **결과 요약**:
   - 각 에이전트의 실행 결과를 사용자에게 요약하여 보고
