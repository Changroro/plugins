# review: 자소서 퇴고 및 검증

작성된 자소서를 다각도로 검증하고 퇴고하는 스킬. 여러 검증 프로세스를 조합하여 최종 품질을 끌어올린다.

## 프롬프트 레퍼런스

플러그인 내 templates 경로를 사용한다.

| 파일 | 용도 | 언제 사용 |
|------|------|---------|
| `templates/클리셰_탈출_가이드.md` | AI 티 7가지 특징 + 금지 표현 20개 + 5단계 퇴고 프로세스 | **항상** (핵심 레퍼런스) |
| `templates/2차_퇴고.md` | STAR 구체화, 수치화, 톤 부여, AI 느낌 제거 등 7가지 원칙 | **항상** (핵심 레퍼런스) |
| `templates/일관성_검증.md` | 내용/톤/직무연관/시간/분량 일관성 6항목 검증 | 전체 자소서 제출 시 |
| `templates/경험_업그레이드.md` | 평범한 경험을 임팩트 있게 변환 | 경험 서술이 약할 때 |
| `templates/표현_업그레이드.md` | 신입의 언어를 매력적인 언어로 환골탈태 | 표현이 밋밋할 때 |

## 실행 흐름

### Step 1: 퇴고 범위 파악

사용자의 요청을 분석:
- **단일 문항 퇴고**: 특정 문항만 다듬기
- **전체 자소서 검증**: 모든 문항의 일관성/품질 종합 검증
- **특정 이슈 수정**: "AI 티 없애줘", "표현 좀 다듬어줘" 등

### Step 2: 레퍼런스 로드

1. `templates/클리셰_탈출_가이드.md` -- 항상 참조 (AI 티 제거의 핵심)
2. `templates/2차_퇴고.md` -- 항상 참조 (7가지 퇴고 원칙)
3. 요청에 따라 추가 레퍼런스 로드

### Step 3: 검증 프로세스 실행

서브에이전트를 활용하여 병렬 검증:

#### 검증 A: 클리셰/AI 티 검사
`templates/클리셰_탈출_가이드.md` 기반으로:
- ChatGPT 7가지 치명적 특징 체크 (과도한 격식, 문장 길이 획일성, 접속사 남발, 구체성 부재, 대명사 반복, 실패/고민 과정 부재, 자기규정형 첫 문장)
- 금지 표현 20개 스캔
- AI 흔적이 드러나는 문장 구조 탐지

#### 검증 B: 7가지 퇴고 원칙 적용
`templates/2차_퇴고.md` 기반으로:
1. STAR 기법 구체화 여부
2. 수치화/정량적 표현 충분한지
3. '나'의 목소리가 살아있는지
4. 기업 인재상과 연결되어 있는지
5. AI 느낌 표현 잔존 여부
6. 경험-직무 간 논리적 간극 여부
7. 소제목 매력도

#### 검증 C: 일관성 검증 (전체 자소서일 때)
`templates/일관성_검증.md` 기반으로:
- 내용/톤/직무연관/시간/분량 일관성 6항목
- 심각도별 문제 분류
- 100점 만점 점수 산출

### Step 4: 수정안 제시

검증 결과를 종합하여:
1. **심각도순 문제 목록** (수정 필요한 부분)
2. **수정된 자소서 Full Text** (Before/After 비교)
3. **잘된 부분** (유지해야 할 강점)
4. **추가 질문** (정보가 부족한 부분)

### Step 5: 반복

사용자 피드백 반영 -> 재퇴고 -> 확인. 사용자가 만족할 때까지 반복.

## 핵심 원칙

- 퇴고 시 **원문의 의도와 소재는 유지**하면서 표현만 개선
- 수정 이유를 항상 설명 (왜 이 표현이 문제인지)
- 과도한 수정보다 **핵심 문제 3-5개에 집중**
- 사용자가 직접 쓴 느낌이 나도록 자연스러운 문체 유지
