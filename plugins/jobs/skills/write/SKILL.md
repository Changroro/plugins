# write: 자소서 문항 작성

자소서 문항을 작성할 때 사용. 문항 유형을 판별하여 적절한 프롬프트 레퍼런스를 참조한 뒤 작성한다.

## 프롬프트 레퍼런스 (templates 폴더)

플러그인 내 templates 경로를 사용한다. 플러그인 루트를 기준으로 `templates/` 폴더에 위치.

### 문항 유형별 레퍼런스 매핑

| 문항 유형 | 참조 파일 | 용도 |
|---------|---------|------|
| 일반/범용 | `templates/자소서_베이직.md` | 기본 자소서 작성 프레임워크 |
| 지원동기 | `templates/지원동기_작성.md` | 3C+1P 프레임워크, 차별화 전략 |
| 입사 후 포부 | `templates/입사후포부_작성.md` | 단기/중기/장기 SMART+MVP |
| 특기/취미 | `templates/특기취미_작성.md` | 직무 연결 스토리텔링 |
| 비전공 분야 지원 | `templates/비전공자_전략.md` | 비전공자 차별화 포지셔닝 |

### 보조 레퍼런스 (필요시 참조)

| 파일 | 용도 |
|------|------|
| `templates/채용공고_분석.md` | 채용공고 심층분석 (6단계) |
| `templates/소재_발굴.md` | 소재가 부족할 때 경험 재가공 |
| `templates/인트로_작성법.md` | 자소서 첫 문장(후킹) 전략 |
| `templates/분량별_전략.md` | 글자수별 최적 구성 전략 |

## 실행 흐름

### Step 1: 문항 유형 판별

사용자가 제공한 문항을 분석하여 유형을 판별:
- "지원동기", "왜 우리 회사" -> 지원동기
- "입사 후 포부", "입사 후 계획", "비전" -> 입사후포부
- "특기", "취미", "여가" -> 특기취미
- "성장과정", "장단점", "역량" 등 일반 문항 -> 베이직
- 비전공 분야 지원 상황이면 `templates/비전공자_전략.md` 추가 참조

### Step 2: 레퍼런스 로드

1. 해당 유형의 프롬프트 레퍼런스 파일을 Read (플러그인 templates/ 경로에서)
2. 필요시 보조 레퍼런스도 Read (글자수 제한 있으면 분량별_전략, 소재 부족하면 소재_발굴)
3. 현재 작업 디렉토리의 리서치 자료도 Read:
   - `./리서치/기업분석.md`
   - `./리서치/직무분석.md`
   - `./채용공고.md`

### Step 3: 사용자 프로필 참조

- `./profile.md` -- 사용자의 프로젝트 서사, 경험 상세
- 이 파일이 없으면 사용자에게 경험/역량을 직접 입력하도록 요청

### Step 4: 작성

레퍼런스의 프레임워크와 가이드를 따라 자소서 문항을 작성. 작성 시 핵심 원칙:

- 나열식이 아닌 **자연스러운 에세이** 형식
- AI 티가 나지 않도록 **리듬감 있는 문장** (길이 다양, 접속사 최소화)
- **구체적 수치와 경험** 기반
- 해당 기업의 인재상과 **자연스러운 연결**
- 글자수 제한 엄수

### Step 5: 결과 제시

- 2~3개 버전 제공 (레퍼런스에서 요구하는 경우)
- 각 버전의 특징과 장단점 설명
- 사용자 선택 후 피드백 반영
