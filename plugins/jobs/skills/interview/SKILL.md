# interview: 면접 준비

작성된 자소서와 이력서를 기반으로 면접을 준비하는 스킬.

## 프롬프트 레퍼런스

플러그인 내 templates 경로를 사용한다.

| 파일 | 용도 |
|------|------|
| `templates/1분_자기소개.md` | 1분 자기소개 작성 (기본형+임팩트형, 후속질문, 연습팁) |
| `templates/면접질문_생성.md` | 서류 교차분석 기반 압박 면접질문 100개 생성 |

## 실행 흐름

### 요청 유형 판별

사용자의 요청에 따라 분기:

1. **"1분 자기소개"** -> 1분 자기소개 작성 모드
2. **"면접 질문" / "예상 질문"** -> 면접질문 생성 모드
3. **"면접 준비" (포괄적)** -> 두 가지 모두 실행
4. **"모의 면접"** -> 면접 시뮬레이션 모드

---

### 모드 1: 1분 자기소개 작성

`templates/1분_자기소개.md` 레퍼런스 기반.

1. 현재 디렉토리의 자소서 Read (`./자기소개서.md`)
2. 채용공고 Read (`./채용공고.md`)
3. 레퍼런스의 4단계 구조(강렬한 시작 -> 핵심경험 -> 직무연결 -> 마무리) 적용
4. **기본형** + **임팩트형** 2개 버전 제공
5. 예상 후속 질문 5개 제안
6. 연습 팁 (강조 포인트, 속도 조절법) 제공

---

### 모드 2: 면접질문 생성

`templates/면접질문_생성.md` 레퍼런스 기반.

1. 3가지 문서 수집:
   - 문서 1: 사용자 프로필 (`./profile.md` -- 없으면 사용자에게 경험/역량 직접 입력 요청)
   - 문서 2: 현재 디렉토리 자소서 (`./자기소개서.md`)
   - 문서 3: 채용공고 (`./채용공고.md`)
2. 4가지 취약점 유형 기반 교차분석:
   - 불일치/모호함
   - 근거 부족
   - 직무 연관성 부족
   - 과장 의심
3. 초개인화 예상 질문 100개 생성
4. 각 질문에 **답변 방향성** 포함 (선택)

---

### 모드 3: 면접 시뮬레이션

사용자가 "모의 면접" 요청 시:

1. 생성된 질문 중 핵심 20개 선별
2. 면접관 역할로 질문 하나씩 제시
3. 사용자 답변에 대해 피드백:
   - 답변의 구체성/논리성 평가
   - 개선 포인트 제시
   - 모범 답변 예시 제공
4. 전체 면접 후 종합 평가

## 참조 자료

면접 준비 시 추가로 참조할 수 있는 자료:
- `./리서치/기업분석.md` -- 기업 관련 질문 대비
- `./리서치/직무분석.md` -- 직무 관련 질문 대비
- `templates/비전공자_전략.md` -- 비전공자 면접 대비 (해당 시)
