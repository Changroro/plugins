# crawl: 채용공고 크롤링

사용자가 제공한 채용공고 URL을 크롤링하여 `채용공고.md`에 정리된 형식으로 저장한다.

## 실행 흐름

### Step 1: URL 수신 및 크롤링

1. 사용자가 제공한 URL을 `WebFetch` (firecrawl-scrape 스킬)로 크롤링
2. 크롤링이 실패하면 `WebSearch` (firecrawl-search 스킬)로 대체 시도
3. 크롤링 결과에서 **회사명**과 **채용 직무명**을 추출
4. 회사명이 불명확하면 사용자에게 확인 질문

### Step 2: 채용공고.md 작성

크롤링한 채용공고 내용을 아래 형식으로 정리하여 `./채용공고.md`에 저장:

```markdown
# {회사명} - {직무명} 채용공고

## 기본 정보
- 회사:
- 직무:
- 고용형태:
- 근무지:
- 마감일:

## 자격 요건
(원문 기반 정리)

## 우대 사항
(원문 기반 정리)

## 주요 업무
(원문 기반 정리)

## 자기소개서 문항
(있을 경우 문항별로 정리, 글자 수 제한 포함)

## 원문 링크
{URL}
```

### Step 3: 자기소개서.md 템플릿 업데이트

채용공고에 자소서 문항이 있으면 `./자기소개서.md`를 업데이트:

```markdown
# {회사명} 자기소개서

## 문항 1: {문항 내용} (xxx자)

## 문항 2: {문항 내용} (xxx자)

...
```

자소서 문항이 없으면 기본 구조만 유지.

### Step 4: 완료 보고

크롤링 결과를 사용자에게 요약 보고:
- 회사명, 직무명
- 자격 요건 핵심 키워드
- 자소서 문항 수 및 글자수 제한
- 다음 단계 안내 (`/research` 스킬로 리서치 실행 권장)
