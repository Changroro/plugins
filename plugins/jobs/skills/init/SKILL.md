# init: 채용 지원 환경 초기화

현재 작업 디렉토리에 채용 지원을 위한 폴더 구조와 기본 파일을 생성한다.

## 실행 흐름

### Step 1: 회사명/직무명 확인

사용자에게 아래 정보를 확인:
1. **회사명** (필수)
2. **직무명** (필수)
3. **채용공고 URL** (선택 - 있으면 crawl 스킬로 연계)

### Step 2: 폴더 구조 생성

현재 작업 디렉토리에 아래 구조를 생성:

```
./
├── CLAUDE.local.md        # 자소서 작업 지침 (자동 생성)
├── 채용공고.md             # 채용공고 내용 정리 (빈 템플릿)
├── 자기소개서.md           # 자소서 작업 파일 (빈 템플릿)
└── 리서치/                 # 리서치 결과물 폴더
    ├── 기업분석.md
    ├── 직무분석.md
    ├── 합격자소서_분석.md
    ├── 유사자소서_분석.md
    └── 자소서_작성팁.md
```

### Step 3: 채용공고.md 빈 템플릿 생성

```markdown
# {회사명} - {직무명} 채용공고

## 기본 정보
- 회사:
- 직무:
- 고용형태:
- 근무지:
- 마감일:

## 자격 요건

## 우대 사항

## 주요 업무

## 자기소개서 문항

## 원문 링크
```

### Step 4: 자기소개서.md 빈 템플릿 생성

```markdown
# {회사명} 자기소개서

## 문항 1:

## 문항 2:
```

### Step 5: CLAUDE.local.md 생성

아래 템플릿을 기반으로 생성. `{회사명}`, `{직무명}`을 실제 값으로 치환:

```markdown
# {회사명} 자기소개서 작업 지침

## 1. 작업 구조 (에이전트 팀 운영)

### 팀 구성
- **팀장(나)**: 사용자 피드백 전달, 클리셰 검증, 전체 품질 관리
- **문항별 팀원**: 각 문항당 1명의 에이전트 팀원 배정 (bypassPermissions 모드)
- **서브에이전트**: 클리셰 검증, 자소서 컨설턴트/인사담당자 평가, 웹검색 등 보조

### 운영 원칙
1. **모든 작업은 에이전트 팀(TeamCreate)으로 진행**. 일반 서브에이전트(Agent)로 직접 수정 금지.
2. **사용자 피드백은 팀장이 직접 수정하지 않음**. 피드백을 다듬어서 해당 문항 담당 팀원에게 SendMessage로 전달.
3. **각 팀원은 맡은 문항 1개만 담당**. 다른 문항 수정 금지.
4. **각 팀원은 서브에이전트를 활용**하여 웹검색, 회사 정보 조사, 표현 개선 등을 자율적으로 수행.
5. **승인된 문항을 임의로 수정하지 말 것**.

### 팀장 역할
- 사용자 피드백 수신 -> 각 팀원에게 구체적 지시 전달
- 수정 완료 후 **매번** 클리셰 검증 서브에이전트 실행
- 주기적으로 자소서 컨설턴트/인사담당자 역할의 서브에이전트를 활용하여 전체 자소서 평가
- 문항 간 소재 중복, 톤 일관성 등 교차 검증

---

## 2. 참고 자료 (반복 참조 필수)

### 회사/직무 분석
- `리서치/기업분석.md` -- {회사명} 기업 분석
- `리서치/직무분석.md` -- {직무명} 직무 상세 분석

### 자소서 리서치
- `리서치/합격자소서_분석.md` -- 합격 자소서 수집 및 패턴 분석
- `리서치/유사자소서_분석.md` -- 동종업계/동일직무 자소서 분석
- `리서치/자소서_작성팁.md` -- 해당 기업 자소서 작성팁, 커뮤니티 후기, 전문가 조언

### 채용공고
- `채용공고.md` -- 채용공고 원문 정리

### 스킬 안내
- 작성: `/write` 스킬 사용 (문항 유형별 자동 판별)
- 퇴고: `/review` 스킬 사용 (클리셰/AI티/일관성 검증)
- 면접: `/interview` 스킬 사용 (1분 자기소개/면접질문)

### 사용자 프로필
- `profile.md` -- 사용자 프로필 (프로젝트 서사 포함). 이 파일이 없으면 사용자에게 생성을 안내할 것.
```

### Step 6: 완료 보고

```
## {회사명} 지원 환경 초기화 완료

### 생성된 파일
- CLAUDE.local.md
- 채용공고.md (빈 템플릿)
- 자기소개서.md (빈 템플릿)
- 리서치/ (빈 폴더)

### 다음 단계
1. 채용공고 URL이 있다면 `/crawl` 스킬로 공고 크롤링
2. `/research` 스킬로 기업/직무/자소서 리서치 실행
3. 자기소개서 작성 시작 (`/write`)
```
